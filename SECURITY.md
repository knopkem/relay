# Security Policy

## Supported Versions

Relay is installed from a repository checkout. Security fixes are made on the
latest commit on `main`; older commits are not maintained.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older commits | No |

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/knopkem/relay/security/advisories/new)
instead of opening a public issue.

Include the affected files or commands, reproduction steps, and the potential
impact. Please do not include credentials, tokens, or other secrets in the
report. We aim to acknowledge reports within seven days and will coordinate a
fix and disclosure timeline with the reporter.
